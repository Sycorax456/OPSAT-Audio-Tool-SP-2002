Un conjunto de utilidades diseñadas en Python para explorar, extraer y manipular los recursos del clásico **Tom Clancy's Splinter Cell (2002)**.

---

## 🛠️ Funcionalidades Principales

Esta herramienta permite interactuar con los archivos internos del juego a través de distintas capacidades:

* **Interfaz Gráfica de Usuario (GUI):** Un panel visual e intuitivo para gestionar todas las funciones de forma accesible sin usar la consola.
* **Gestión de Archivos Empaquetados:** Permite examinar y descomprimir las estructuras de datos y contenedores originales del juego de Ubisoft.
* **Conversión de Audio:** Herramienta especializada para decodificar y reproducir los formatos de sonido comprimido (ADPCM) utilizados en los archivos de audio del título.
* **Manipulación de Gráficos:** Utilidad orientada a la lectura, exportación y gestión de texturas e imágenes (`.ima`) del motor gráfico original.

---
